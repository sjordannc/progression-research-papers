# Research papers by Scott A. Jordan

This repository collects three distinct research manuscripts. They are shared as drafts for reading and discussion; their inclusion here does not imply peer review or empirical validation.

| Manuscript | Files | Scope |
| --- | --- | --- |
| **Progression Geometry as a Complete Gravitational Field** (July 2026) | [LaTeX source](progression_geometry_current_theory_flrw.tex) | Main progression-geometry theory, including the Einstein benchmark, infrared deformation, stability, post-Newtonian limit, and FLRW cosmology. This is the latest version in this collection. |
| **Interaction Complexity as a Covariant Source for Progression Geometry** (draft, July 2026) | [PDF](interaction_complexity_progression_geometry.pdf) · [LaTeX source](interaction_complexity_progression_geometry.tex) | A separate two-current source-sector proposal and its consistency conditions. |
| **Relational Spectral Inertia from Cosmological Frame Dragging** (draft, September 2026) | [PDF](relational_spectral_inertia_draft.pdf) | A speculative modified-inertia framework, distinct from the progression-geometry source model. |

The latest progression-geometry manuscript is currently provided as LaTeX source only. An earlier PDF in the author's working folder predates its FLRW section, so it is not presented here as a PDF of the latest manuscript. The source is self-contained and uses standard LaTeX packages listed in its preamble.

Earlier scalar-progression drafts, standalone matter and optics drafts, and the separate FLRW note are omitted from this collection because their development or results are substantially covered by the main manuscript. The separate [weighted-conservation repository](https://github.com/sjordannc/weighted-conservation) contains related galaxy-test data and code.
